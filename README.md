To run the code, you need to download three sets of pre-trained word vectors [here](https://chuck.stanford.edu/chai/data/glove/) and put them in the `lib/` folder.

## [Project 2](https://ccrma.stanford.edu/wiki/356-winter-2026/hw2): Featured Artist

- Download the [wav file](https://ccrma.stanford.edu/~lejun/356/hw2/data/the-rite-of-spring.wav) and the [extracted feature file](https://ccrma.stanford.edu/~lejun/356/hw2/data/the-rite-of-spring.txt) to the `data/` folder.
- Run `chuck kandinsky.ck:data/the-rite-of-spring.txt`.
- Draw according to your like!
